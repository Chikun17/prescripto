
# Prescripto 🏥

Prescripto is a full-stack doctor appointment booking platform built using the MERN stack. It allows patients to find doctors, book appointments, manage their profiles, and make payments. It also provides separate dashboards for doctors and administrators.

## 🚀 Features

### 👤 User / Patient
- User registration and login
- Browse available doctors
- View doctor profiles and availability
- Book doctor appointments
- Manage appointments
- User profile management
- Online payment integration

### 👨‍⚕️ Doctor
- Doctor authentication
- Doctor dashboard
- View and manage appointments
- Manage doctor profile
- Update availability
- Track appointment information

### 🛠️ Admin
- Admin authentication
- Admin dashboard
- Add and manage doctors
- View registered users
- Manage appointments
- Manage doctor information
